# Mini Arcade 🎮

A small, beginner-friendly browser project with two mini-games:

- **Guess the Number** — find the secret number from 1 to 100 in seven attempts.
- **Rock, Paper, Scissors** — play against the computer and keep score.

## Run it

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Play—no installation or server required.

## Files

- `index.html` — page structure and game controls
- `style.css` — responsive styling
- `script.js` — game logic

## Built with

HTML, CSS, and vanilla JavaScript.
